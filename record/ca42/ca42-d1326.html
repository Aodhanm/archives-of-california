'Que manden noticia de las causas existentes.' [= that they send a return of the causes now pending]

Departmental State Papers, Benicia, tomo Prefecturas y Juzgados I–VI · BANC MSS C-A 42, document 1326

'Que manden noticia de las causas existentes.' [= that they send a return of the causes now pending]. An order for docket returns from every command. Directly bears on the Alcalde Rule question of whether pending-causa returns were ever compiled; Savage supplies neither date nor place, writing '(Sin fecha ni lugar)' where the heading line would be.
