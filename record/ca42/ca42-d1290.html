Departmental State Papers, Benicia, tomo Prefecturas y Juzgados I–VI · BANC MSS C-A 42, document 1290

MARQUEE for the Alcalde Rule project. Governor forbids the alcalde ever to use arms in apprehending defenceless citizens. Verbatim: 'Que nunca haga uso de armas para la aprencion de ciudadanos sin defensa.' [= that he never use weapons to arrest defenceless citizens]. Second sub-entry of the same grouped heading; an explicit gubernatorial limit on an alcalde's coercive power.
