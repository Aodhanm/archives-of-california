SESSION ACTA Heading verbatim: '+ 1834 = Julio 19. = Mont. / Diputacion Territorial' [= 1834, July 19, Monterey. Territorial Diputación.] Savage abstract, three lines: 'Dice: aprovada la acta anterior. Se dió cuenta con varios dictámenes sobre terrenos.' [prior acta approved; several dictámenes on lands laid before the body]. A session date that appears NOWHERE in the first July run, so it is recoverable only from this second run.
