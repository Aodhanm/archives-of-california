# 'Enterado qe hizo entrega del mando á Tente Ignacio Martinez; qe pr ningun crimen se le manda á Mont, sino pr qe así con

**C-A 47 (Departmental Records), scan n336** · Sav p.  · tomo p. p.577-79 · 1828-11-20 · Savage abstract · 

'Enterado qe hizo entrega del mando á Tente Ignacio Martinez; qe pr ningun crimen se le manda á Mont, sino pr qe así conviene al servicio' — acknowledges he handed the command to Tente Ignacio Martinez; that he is sent to Monterey for no crime, but because it so suits the service.
