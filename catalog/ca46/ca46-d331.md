# 'de ningn modo se les puede faltar á la Racn cargando al fondo de gratificacion las qe se les suministren á los Inds com

**C-A 46 (Departmental Records), scan n244** · Sav p. 241 / 240. · tomo p. p.180 · 1824-03-23 · Savage abstract · 

'de ningn modo se les puede faltar á la Racn cargando al fondo de gratificacion las qe se les suministren á los Inds como se ha acostumbrado pr correccn pa los Presidars el real y medio qe les correspe haciendo este cargo á la misma Nacion pr ser sentenciados pr sus delitos' — rations for convicts (presidiarios) at San Diego must not fail: real y medio charged to the nation, Indian issues to the gratificación fund.
