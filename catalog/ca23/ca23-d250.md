# 'Sobre derechos de Alcabala á Indios.' VERBATIM: 'Dice qe aunque pr órden de Comandᵗᵉ Genl 28 Abril, se previene no se c

**C-A 23 (Provincial Records), scan n125** · Sav p. 123 · tomo p. p.241-242 · 1783-07-13 · Savage abstract · 

'Sobre derechos de Alcabala á Indios.' VERBATIM: 'Dice qe aunque pr órden de Comandᵗᵉ Genl 28 Abril, se previene no se cobre alcabala á los Indios pr los frutos de sus Misiones, no se resolverá á ordenar á Cañete qe devuelva las cantidades qe les ha cobrado, hasta no recibir órden de aquel sobre el particular.' [Though the 28 April order forbids charging alcabala to the Indians for their missions' produce, Fages will not order Cañete to refund sums already collected until receiving specific order.]
