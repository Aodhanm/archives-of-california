# Premio á la Agricultura: 'Está muy contento pr que se condujo la presa para prover de agua los trigos. Que se siembre to

**C-A 23 (Provincial Records), scan n470** · Sav p. 186 · tomo p. p.449 · 1796-03-29 · Savage abstract · 

Premio á la Agricultura: 'Está muy contento pr que se condujo la presa para prover de agua los trigos. Que se siembre todo lo mas que se pueda; que para estimular la siembra de maiz ofrece un premio de $25 en jéneros á costo y costas para el que coseche mas maiz' — pleased the dam now waters the wheat; $25 prize in goods for the biggest maize harvest.
