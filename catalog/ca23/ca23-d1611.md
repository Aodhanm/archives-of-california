# 'Que mande á jornadas dobles todo el cáñamo; que si se opone Bello lo engrille y lo mande preso á Sn Francisco' — send a

**C-A 23 (Provincial Records), scan n547** · Sav p. 259 · tomo p. p.742 · 1797-10-27 · Savage abstract · 

'Que mande á jornadas dobles todo el cáñamo; que si se opone Bello lo engrille y lo mande preso á Sn Francisco' — send all hemp by double stages; if Bello resists, iron him and send him prisoner to San Francisco.
