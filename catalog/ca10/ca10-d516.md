# Spans n332-n333. 'qe recibió lista de cosechas de Branciforte; qe aprueba qe del levantado pr unos se socorra á los otro

**C-A 10 (Provincial State Papers), scan n332–n333** · Sav p. 332/330 · tomo p. p.874 · 1799-11-09 · Savage abstract · 

Spans n332-n333. 'qe recibió lista de cosechas de Branciforte; qe aprueba qe del levantado pr unos se socorra á los otros, cuando estos ya no tengan' [= acknowledges the Villa de Branciforte harvest return and approves redistributing surplus grain from the better-off settlers to those who run out].
