# 3o of the stack; its own date line 'Enero 11' opens n194, so the dates run backwards while the page cites run forward. '

**C-A 62 (Archives of California, Miscellaneous), scan n194** · Sav p. 172 [stamp] / 11 [hand] · tomo p. p. 148. · 1848 Enero 11 · Savage abstract · 

3o of the stack; its own date line 'Enero 11' opens n194, so the dates run backwards while the page cites run forward. 'Pide le remita á la Comand.a Gral. á los Sres. Juan Hipolito y José M.a Cota; asimismo á los Ingleces é Americanos que vivian en el Veladero, tan luego como estos ult.s regresasen de la Salada' [= send in to headquarters the Cota brothers, and likewise the English and Americans living at El Veladero as soon as the latter return from La Salada].
