# Detailed HABILITADO handover/accounting instruction (*reintegros*): peritos + entrega/avalúo; the Habilitados formalize 

**C-A 2 (Provincial State Papers), scan n290–n296** · Sav p. 287–293 · tomo p. — · 1781-08-13 · Savage abstract · 

Detailed HABILITADO handover/accounting instruction (*reintegros*): peritos + entrega/avalúo; the Habilitados formalize accounts so they aren't liable to the Rᶫ Tribunal de Cuentas for prior years; the *alcances* since 1774; a worked example (géneros $2,500 / efectos $3,700 / víveres $1,500 / the 108% mule-horse recargo $350 / total $7,750; company alcances by end-1780 = $19,230); + the 'second inventory' enumerating warehouse-goods categories (non-distributable géneros, damaged effects, víveres, mining/foundry, arsenal) — the habilitado fiscal machinery. ⚠ Savage notes missing leaves ('parece faltar una ó varias hojas')
