# Returns the budget for the Diputación's hall to be corrected, since it omits 'papel para entapizado, alfombrado p.a el p

**C-A 20 (Dep. State Papers, Benicia (Military)), scan n496** · Sav p. 497/19 · tomo p. p.175-176 · 1834-01-02 · Savage abstract · 

Returns the budget for the Diputación's hall to be corrected, since it omits 'papel para entapizado, alfombrado p.a el piso, asientos menos p.a el público, campanilla, escudo de armas, recado de escribir, cortinas p.a puertas y ventanas &a. Todo esto me parece indispensable y conven.te al decoro y dignidad de aquella corporacion'; although there is nowhere to buy the goods nor money for them, they should be budgeted; and for the immediate purchases 'negociaré un préstamo, y al efecto espero á V.d p.a que conferenciemos sobre el particular'.
