# SESSION ACTA catalogued by the ca60 DECOMPOSITION 2026-08-27: it had no record of its own, lying inside an umbrella band

**C-A 60 (Legislative Records), scan n220-n221** · Sav p. corner stamps 221-222 / ink 219-220 · tomo p. p.p. 274 = 77. · 1835-09-12 · Savage abstract · 

SESSION ACTA catalogued by the ca60 DECOMPOSITION 2026-08-27: it had no record of its own, lying inside an umbrella band that spanned n220-n245. Heading verbatim: '+ 1835. = Sbre 12. = Mont. / Diputacion Territorial' [= 1835, September 12, Monterey. Territorial Deputation (session record).] A four-page acta in the original which Savage compresses into a single line straddling the leaf break: 'Sobre Concecion de terrenos' (n220, last line) / 'á varios' (n221, first line). On the concession of lands to various persons. Unusually for this run there is no 'Dice: Aprovada acta anterior' formula and no grantee, place or acreage is carried over into the copy. This is the '⭐ Concesión de terrenos' item that record d17 advertises; because the acta is split across the leaf break it is easy to miss entirely. Because it straddles n220/n221 and Savage names nobody, the original grants can only be recovered from the parallel land-grant expediente series.
