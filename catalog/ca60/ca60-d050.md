# SESSION ACTA catalogued by the ca60 DECOMPOSITION 2026-08-27: it had no record of its own, lying inside an umbrella band

**C-A 60 (Legislative Records), scan n165** · Sav p. n165 stamp 166 / ink 164 · tomo p. pp. 189 = 91 · 1834-07-19 · Savage abstract · 

SESSION ACTA catalogued by the ca60 DECOMPOSITION 2026-08-27: it had no record of its own, lying inside an umbrella band that spanned n151-n189. Heading verbatim: '+ 1834 = Julio 19. = Mont. / Diputacion Territorial' [= 1834, July 19, Monterey. Territorial Diputación.] Savage abstract, three lines: 'Dice: aprovada la acta anterior. Se dió cuenta con varios dictámenes sobre terrenos.' [prior acta approved; several dictámenes on lands laid before the body]. A session date that appears NOWHERE in the first July run, so it is recoverable only from this second run.
